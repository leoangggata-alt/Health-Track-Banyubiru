Panduan Admin

  • Gunakan filter tanggal, kelas, dan program untuk memuat dashboard server.
  • Kelola identitas sekolah, kelas, siswa, dan program dari menu utama.
  • Reset PIN membuat kredensial baru; PIN tidak pernah ditampilkan kembali oleh portal.
  • Laporan dan CSV mengikuti cakupan program/kelas terpilih.
  • Arsip tenant memerlukan kode sekolah dan dicatat dalam audit server.
Semua akses dibatasi tenant dari sesi server, bukan ID sekolah dari browser.

Arsipkan Pengisian?

Operasi ini mengarsipkan pengisian tenant. Ketik kode sekolah untuk melanjutkan.

🔄

Mulai Ulang / Restart Program 30 Hari

Aksi ini akan me-restart hitungan siklus program untuk sekolah ini per lisensi aktif. Seluruh aplikasi siswa di sekolah ini akan otomatis sinkron dan dimulai kembali dari Hari ke-1/30 terhitung sejak tanggal mulai yang Anda tentukan.

📌 Catatan: Siklus program sebelumnya akan diarsipkan di server. Riwayat pengisian checklist siswa terdahulu tetap tersimpan aman di database sekolah.
